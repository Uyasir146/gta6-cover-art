GTA Cover Studio: an offline browser app that turns your own photos and a caption into multi-panel GTA-style cover art and exports a PNG at 1080x1080, 1080x1350 or 1920x1080. Photos never leave the machine, no build step, no network requests.

## Run it

```sh
node serve.ts   # then open http://localhost:8080
```
